## Fluxos n8n

Aqui vão os fluxos que criei com o n8n. Cada arquivo .json está pronto pra importar.

### Como importar no n8n
1. Abra o n8n
2. Clique em "Import from File" ou "Import from Clipboard"
3. Selecione o .json ou cole o conteúdo
4. Salve e ative
